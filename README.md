# Vocab Runner 👨‍🚀

เกม endless runner 3 มิติสไตล์ Subway Surfers สำหรับฝึกคำศัพท์อังกฤษ
คุณคือ**นักบินอวกาศ**วิ่งอยู่ใน**ทางเดินสถานีอวกาศ** อ่านโจทย์ภาษาไทยด้านบน
แล้ววิ่งทะลุประตูที่มีคำอังกฤษถูกต้อง — เลือกผิดคือจบรอบ

**ไม่ต้องใช้ Node, ไม่ต้อง npm install, ไม่มี build step**

---

## วิธีเล่น

```bash
python3 vocab-runner/serve.py
```

แล้วเปิด <http://localhost:8080> (หรือ `cd vocab-runner && python3 serve.py`)

> **ทำไมใช้ `serve.py` ไม่ใช่ `python3 -m http.server`?**
> `http.server` ปกติไม่ส่ง cache header เบราว์เซอร์เลยแคชไฟล์ไว้ พอคุณแก้ deck
> หรือแก้โค้ดแล้ว reload จะยังเห็นของเก่า `serve.py` สั่งห้ามแคชทุกไฟล์ →
> reload ทีเดียวเห็นของใหม่เสมอ (ดูเหตุผลเต็มในหัวไฟล์ `serve.py`)
>
> ถ้าจะใช้ `python3 -m http.server 8080` ก็ยังเล่นได้ แต่หลังแก้ไฟล์ต้อง
> **hard-reload** (Cmd+Shift+R / Ctrl+Shift+R) เพื่อล้างแคช

> ⚠️ **ห้ามเปิดด้วยการดับเบิลคลิกไฟล์ `index.html`**
> เบราว์เซอร์บล็อก `fetch()` บน protocol `file://` ด้วยเหตุผลด้านความปลอดภัย (CORS)
> เกมจะโหลดชุดคำไม่ได้
>
> ⚠️ **ใช้พอร์ต 8080 เสมอ** — สถิติเก็บใน `localStorage` ซึ่งผูกกับ origin
> ถ้าเปลี่ยนเป็นพอร์ต 8081 สถิติจะ "หายไป" (จริง ๆ ยังอยู่ แต่คนละบ้าน)
> (เลือก 8080 เพราะพอร์ต 8000 ในเครื่องคุณถูก Docker ใช้อยู่)

### ปุ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| `←` `→` หรือ `A` `D` | เปลี่ยนเลน = **ตอบคำถาม** |
| `↑` / `W` | กระโดดข้ามสิ่งกีดขวาง / **กระโดดขึ้นหลังคายานลำเลียง** |
| `↓` / `S` | สไลด์ลอดใต้คาน |
| `Space` (ระหว่างวิ่ง) | **ใส่ไอพ่นที่เก็บมา** — บนมือถือใช้แตะจอ |
| `Space` (นอกเกม) | เริ่มเกม / เล่นใหม่ |
| `Esc` | พัก / กลับเมนู |
| ปัดนิ้ว | ใช้ได้ทั้ง 4 ทิศบนจอสัมผัส |

สังเกตว่า **ซ้าย-ขวา = ตอบคำถาม** ส่วน **ขึ้น-ลง = เอาตัวรอด** — แยกกันคนละแกนโดยตั้งใจ

## กติกา

- คำตอบ 3 ตัวเลือกขึ้นเป็น **"ธง" บนจอ** ไม่ใช่ป้ายในโลก 3D — สีแถบบนธงตรงกับ**สีแผ่นพื้นของเลนนั้น** นั่นคือตัวบอกว่าธงใบไหนคือเลนไหน
- พอหมดเวลา **ป้อมปืนจะยิงเลเซอร์ลงทุกเลนที่เป็นคำตอบผิด** — อยู่ผิดเลนคือจบรอบ
- **1 ชีวิต** โดนเลเซอร์หรือชนสิ่งกีดขวาง = จบรอบทันที
- คำที่ทำให้ตาย จะกลายเป็น**ด่านแรกของรอบถัดไป** — ทุกครั้งที่ตายคือการได้ซ้อมคำที่เพิ่งพลาด
- ตอบถูกติดกันได้ตัวคูณคะแนนสูงสุด ×5
- สิ่งกีดขวางจะโผล่เฉพาะ "ช่วงพัก" ระหว่างด่านเท่านั้น ไม่มีทางโผล่ตอนคุณกำลังอ่านโจทย์

### อันตรายระหว่างทาง 5 ชนิด

| อันตราย | แก้ยังไง | โผล่เมื่อไหร่ |
|---|---|---|
| ☄️ **อุกกาบาต** | กระโดดข้าม (`↑`) | ตั้งแต่ต้นเกม |
| 🛰️ **ขยะอวกาศ** ห้อยลงมา | สไลด์ลอด (`↓`) | ตั้งแต่ต้นเกม |
| ⛔ **ม่านพลังงาน** เต็มความสูง | **เปลี่ยนเลนเท่านั้น** กระโดด/สไลด์ไม่ช่วย | หลังผ่านด่านที่ 7 |
| 🚃 **ยานลำเลียง** ยาวเต็มเลน | **กระโดดขึ้นไปวิ่งบนหลังคา** (มีเหรียญบนนั้น!) หรือหลบเลน — วิ่งชนข้าง/หน้าตัวยาน = จบ | หลังผ่านด่านที่ 2 |
| 🚄 **ยานวิ่งสวน** ไฟหน้าจ้า+เสียงหวูดเตือน | **เปลี่ยนเลนเท่านั้น** พุ่งเร็วมาก กระโดดไม่พ้น | หลังผ่านด่านที่ 8 |

ชนิดที่สามมีไว้เพื่อดึง "แกนซ้าย-ขวา" เข้ามาในเกมหลบด้วย — สองชนิดแรกแก้ด้วยปุ่มขึ้น/ลงล้วน ๆ
ผู้เล่นจะไม่เคยต้องคิดเรื่องตำแหน่งเลย พอมีม่านพลังงาน คุณต้องวางแผนว่า
*"หลบไปเลนไหน แล้วเลนนั้นจะกลับมาตอบคำถามทันไหม"*

**ความยากไต่ขึ้น 3 แกนแยกกัน** (`pacing.obstacleRamp`):

| ผ่านด่านที่ | จำนวนคลื่น/ช่วงพัก | มาพร้อมกันกี่เลน | เวลาให้ตอบสนอง |
|---|---|---|---|
| 0 | 0–1 | 1 | 1.60 วิ |
| 9 | 1–2 | 1 | 1.35 วิ |
| 15 | 2 | **2** | 1.20 วิ |
| 30 | 3 | 2 | 0.95 วิ (พื้น) |

> **กฎความปลอดภัยที่บังคับในโค้ด: ห้ามบล็อกครบทั้ง 3 เลนในเวลาเดียวกันเด็ดขาด**
> ตายโดยไม่มีทางเลือกไม่ใช่ "ยาก" แต่คือ "ไม่ยุติธรรม" และผู้เล่นแยกออกเสมอ
> (ทดสอบแล้วจาก 15 คลื่นที่สุ่มมา ไม่มีคลื่นไหนบล็อกเกิน 2 เลน)

### เหรียญ กับ ไอพ่น

- **เหรียญ** (+5 คะแนน) วางเป็นแถวยาว 5–9 เม็ดทุกช่วงพัก มีโอกาส ~45% ที่จะมี**แถวที่สองอีกเลน**
  และมีแถวพิเศษ**บนหลังคายานลำเลียง** — เหรียญอยู่ใน**เลนที่ไม่มีสิ่งกีดขวาง**เสมอ
  → แถวเหรียญคือตัวชี้ทางปลอดภัยโดยไม่ต้องมี UI บอก
- **ไอพ่น** 🚀 วางไว้ท้ายแถวเหรียญ เก็บเข้าคลังได้สูงสุด 2 ชิ้น — **เก็บมาเฉย ๆ ยังไม่กันอะไร!**
  ต้องกด `Space` (หรือแตะจอ) เพื่อ **"ใส่"** ก่อน — ใส่แล้วมีเปลวไฟที่หลังตลอด (เท่มาก)
  และ**กันตายได้ 1 ครั้ง ทุกสาเหตุ**: ตอบผิด / ชนสิ่งกีดขวาง / ชนยาน — ใช้แล้วเปลวดับ ต้องใส่ชิ้นใหม่
  ตอบผิดแล้วไอพ่นช่วย ยังนับว่าตอบผิดอยู่ (คำตกกล่อง 1 ถูกคิวมาถามใหม่) — รอดในเชิงเกม
  แต่ไม่รอดในเชิงการเรียนรู้ ซึ่งเป็นสิ่งที่ตั้งใจ

> **ทำไมไอพ่นต้องกดใส่เอง?** ของที่ทำงานอัตโนมัติคือ "ประกันเงียบ ๆ" ที่ผู้เล่นลืมไปเลยว่ามี
> ของที่ต้องกดใช้คือ **การตัดสินใจ** — จะใส่ตอนนี้เลย หรือเก็บไว้ก่อนช่วงยาก?
> เกมได้จังหวะ "คิดเชิงกลยุทธ์" เพิ่มมาอีกชั้นโดยไม่ต้องเพิ่มกลไกอะไรเลย

### ⭐ ด่านโบนัส "ทางช้างเผือก"

**เก็บดาว 5 ดวง** → นักบินอวกาศทะยานพ้นทางเดินสถานีขึ้นสู่ห้วงอวกาศ 14 วินาที

- ดาวอยู่**ระดับอกตอนวิ่ง — วิ่งผ่านในเลนเดียวกันก็เก็บได้เลย** (จะกระโดดผ่านก็ได้)
  ~~เดิมตั้งไว้สูงต้องกระโดด แต่ยอดกระโดดกลับสูงเกินดาวเลยพลาดเป็นบางครั้ง จึงลดลงมาให้เก็บง่ายเหมือนเหรียญ~~
- ในด่านโบนัส **ไม่มีอะไรทำอันตรายคุณได้เลย** ไม่มีเลเซอร์ ไม่มีอุกกาบาต ไม่มีการตาย
- **ไม่มีคำถามใด ๆ** — หน้าที่ของด่านโบนัสคือ *ปลดความกดดันล้วน ๆ* (กล่องโจทย์และธงถูกซ่อนไปเลย)
- **เลื่อนได้แค่ซ้าย/ขวา** — ปุ่มขึ้น/ลงถูกปิดระหว่างบิน เหรียญทุกใบวางที่ระดับบินพอดี กวาดเก็บได้หมด
- เหรียญมีค่า **×2** และวางเป็นลวดลายต่อเนื่อง (เส้นตรง / คลื่นสลับเลน ฯลฯ)

> **ทำไมตัดคำถาม/ปุ่มขึ้น-ลงออก?**
> เกมที่กดดันตลอดเวลาทำให้คนเลิกเล่นเร็ว เพราะไม่มีจังหวะให้รู้สึกเก่ง
> ด่านโบนัสจึงเหลือแค่ "บินกวาดเหรียญ" อย่างเดียว — ง่ายที่สุด สนุกที่สุด
> อยากได้มุกกวนกลับมา ตั้ง `bonus.jokeGates: true` ใน `config.js` (มุกอยู่ที่ `decks/jokes-th.json`)
> อยากได้เหรียญ 2 ชั้นแบบเดิม ตั้ง `bonus.singleLevel: false` (ปุ่มขึ้น/ลงต้องแก้ `player.js` เพิ่ม)

### โจทย์สลับ 3 รูปแบบ

| รูปแบบ | หน้าตา | ฝึกอะไร |
|---|---|---|
| **อ่าน** | คำแปลไทย | เห็นความหมาย → นึกรูปคำอังกฤษออก |
| **ดู** | **รูปถ่ายจริงจากคลังภาพเสรี Openverse** (โชว์อีโมจิก่อนระหว่างรอโหลด) | เชื่อมคำกับภาพตรง ๆ ไม่ผ่านภาษาแม่ |
| **ฟัง** | 🔊 อ่านออกเสียง **พร้อมคำแปลไทย** (เล่นซ้ำเมื่อเวลาเหลือครึ่ง) | ได้ยินเสียง + รู้ความหมาย → เลือกรูปคำอังกฤษ |

เหตุผลที่ต้องสลับ: ความจำที่ผูกกับช่องทางเดียวจะใช้ได้แค่ในช่องทางนั้น
คนที่ฝึกจากตัวหนังสืออย่างเดียวมักลงเอยที่ "อ่านออกแต่ฟังไม่ออก"

**ตอบเสร็จทุกครั้ง ธงทั้ง 3 ใบจะเผยคำแปลไทยของตัวเอง** (ใบที่ถูกเป็นสีเขียว) —
ปิดวงจร "เห็นคำ↔รู้ความหมาย" ตอนที่สมองกำลังลุ้นผลพอดี ซึ่งเป็นจังหวะที่จำได้แน่นที่สุด

> โหมด "ดู" จะโผล่เฉพาะคำที่มี `emoji` ใน deck — รูปจริงโหลดจากเน็ตครั้งแรกต่อคำ
> แล้วแคชใน localStorage; ถ้าออฟไลน์/หารูปไม่เจอ จะใช้อีโมจิแทนโดยอัตโนมัติ (เกมไม่พัง)
> โหมด "ฟัง" จะโผล่เฉพาะเมื่อเครื่องอ่านออกเสียงของเบราว์เซอร์ทำงานจริง

### 🎮 เล่นหลายคน — แข่งสด (P2P)

กดปุ่ม **"เล่นหลายคน"** ในเมนู → สร้างห้อง ได้ **รหัส 4 ตัว** บอกเพื่อน →
เพื่อนพิมพ์รหัสเข้าห้อง → หัวห้องกด **เริ่มแข่ง** → นับถอยหลัง 3-2-1 ออกตัวพร้อมกัน

- ทุกคนใช้ **ชุดคำเดียวกัน** (ตามที่หัวห้องเลือกไว้) แต่โจทย์ของใครของมัน
- **ตารางคะแนนสด** มุมขวาล่าง อัปเดตแบบเรียลไทม์ ใครตายขึ้น 💀 คะแนนล็อกทันที
- จบรอบ กด "เล่นอีกครั้ง" = กลับเข้าห้องเดิม หัวห้องกดเริ่มรอบใหม่ได้เลย
- เชื่อมต่อแบบ **P2P (WebRTC)** — ไม่มีเซิร์ฟเวอร์เกม ไม่ต้องสมัครบัญชีใด ๆ
  ใช้ broker ฟรีของ PeerJS แค่ตอน "จับคู่" หลังจากนั้นข้อมูลวิ่งตรงระหว่างเครื่อง

> **ปรัชญา "โลกใครโลกมัน"**: เราไม่ sync ทุกวัตถุในเกม (ต้องรื้อ engine เป็น deterministic)
> แต่ส่งแค่ *สถานะสรุป* (คะแนน/ด่าน/รอด-ตาย) ไม่กี่ครั้งต่อวินาที
> นิยามการแข่งจึงเป็น "ใครทำคะแนนสูงสุด" — เบา ทนเน็ตช้า และไม่กระทบโหมดเล่นเดี่ยวเลย
>
> ⚠️ ข้อจำกัดของ P2P: บางเครือข่าย (NAT เข้มงวด, ไฟร์วอลล์องค์กร) อาจต่อกันไม่ติด
> ถ้าเข้าห้องไม่ได้ ให้ลองเปลี่ยนเครือข่าย (เช่น hotspot มือถือ)

## เสียงไม่ออก? ตรวจตรงนี้ก่อน

หน้าเมนูมีปุ่ม **🔊 ทดสอบเสียงอ่าน** — กดแล้วมันจะบอกตรง ๆ ว่าเกิดอะไรขึ้น
เพราะ `speechSynthesis` ของเบราว์เซอร์พังแบบ "เงียบสนิทไม่มี error" ได้หลายทาง:

| ข้อความที่ขึ้น | แปลว่า |
|---|---|
| ✓ ใช้งานได้ | เครื่องอ่านทำงาน — ถ้ายังไม่ได้ยินให้เช็กระดับเสียงเครื่อง |
| หน้าเว็บไม่ได้อยู่ด้านหน้า | เบราว์เซอร์พักเครื่องอ่านเมื่อแท็บถูกซ่อน ให้สลับกลับมาที่แท็บนี้ |
| ✗ ไม่ตอบสนอง / อ่านออกเสียงไม่ได้ | เครื่องยนต์ค้าง — เกมจะ **ข้ามโหมดฟังให้อัตโนมัติ** ไม่มีทางเจอโจทย์ที่ตอบไม่ได้ |

สิ่งที่โค้ดกันไว้ให้แล้ว (อยู่ใน `src/audio.js`):
เลือกเฉพาะเสียงที่ติดตั้งในเครื่อง (เลี่ยงเสียงแบบเครือข่ายที่เงียบตอนเน็ตมีปัญหา),
เลี่ยงเสียงล้อเล่นของ macOS (Boing, Bad News…), ไม่ `cancel()` พร่ำเพรื่อ,
เลื่อน `speak()` ไปทาสก์ถัดไป, มี watchdog ลองใหม่ให้ 1 ครั้ง,
และ **หรี่เสียงเพลงลงระหว่างอ่านคำ** เพื่อไม่ให้คำจมหายไปกับเสียงเครื่องยนต์

## ชุดคำที่มีให้ + เพิ่มชุดของตัวเอง

เลือก deck ได้ที่เมนู มีให้ 6 ชุด:

| ชุด | จำนวน | เหมาะกับ |
|---|---|---|
| ศัพท์พื้นฐาน A2–B1 | 178 คำ | ครบทุกชนิดคำ ใช้จูนความเร็ว |
| 🐘 สัตว์ | 204 คำ | โหมด "ดูรูป" (96 คำมี emoji) — สัตว์เลี้ยง ฟาร์ม ป่า ทะเล นก แมลง |
| 👕 เสื้อผ้าและเครื่องแต่งกาย | 205 คำ | เสื้อ กางเกง รองเท้า หมวก กระเป๋า เครื่องประดับ ส่วนประกอบ เนื้อผ้า |
| 🏃 กริยาที่ใช้บ่อย | 204 คำ | เคลื่อนไหว กิจวัตร คิด สื่อสาร อารมณ์ ประสาทสัมผัส |
| 📦 คำนามในชีวิตประจำวัน | 203 คำ | บ้าน อาหาร ผลไม้ ร่างกาย สถานที่ ธรรมชาติ ยานพาหนะ (139 คำมี emoji) |
| 💰 ศัพท์การเงิน | 19 คำ | ตัวอย่าง deck เฉพาะทาง |

> ⚠️ **คำแปลสร้างจากความรู้ของ AI** — คำหายากบางคำ (สัตว์แปลก/ศัพท์เฉพาะ) อาจมีคำแปล
> ไม่ตรงเป๊ะ เจอตรงไหนแก้ใน `decks/*.json` ได้เลย (แต่ละคำอยู่บรรทัดเดียว หาง่าย)

> deck ที่มี emoji เยอะ (สัตว์ / เสื้อผ้า / คำนาม) จะเจอโหมด "ดูรูป" บ่อย
> ทำให้เชื่อมคำกับภาพได้ตรง ๆ เหมาะกับการเริ่มต้นเป็นพิเศษ

### เพิ่มชุดคำของตัวเอง

1. คัดลอก `decks/animals.json` (หรือ deck ไหนก็ได้) เป็นชื่อใหม่ เช่น `decks/my-words.json`
2. แก้ `id`, `name` และรายการ `words`
3. เพิ่มบรรทัดใน `decks/index.json`
4. reload — ถ้ารันด้วย `serve.py` จะเห็นทันที (ถ้าใช้ `http.server` ต้อง hard-reload)

รูปแบบของหนึ่งคำ:

```json
{ "en": "anxious", "th": "กังวล", "pos": "adj", "level": 2, "topic": "feeling" }
```

| ฟิลด์ | ใช้ทำอะไร | ค่าที่ใช้ได้ |
|---|---|---|
| `en` | คำที่โผล่บนกำแพง | — |
| `th` | โจทย์ที่โผล่บน HUD | — |
| `pos` | ชนิดคำ — ใช้เลือกตัวลวงให้เป็นชนิดเดียวกัน ไม่งั้นผู้เล่นเดาถูกจากไวยากรณ์ | `noun` `verb` `adj` `adv` |
| `level` | ความยาก ใช้จับคู่ตัวลวงที่ยากพอ ๆ กัน | `1`–`3` |
| `topic` | หมวดความหมาย ใช้*หลีกเลี่ยง*ตัวลวงที่ใกล้เกินไปตอนเจอคำใหม่ | ตั้งชื่อเองได้ |

**ข้อควรระวังที่สำคัญที่สุด:** อย่าใส่คำที่คำแปลไทยทับกันใน deck เดียวกัน
(เช่น `anxious` = กังวล กับ `nervous` = กังวลใจ) เพราะเกมอาจสุ่มทั้งคู่มาเป็นตัวเลือก
แล้วผู้เล่นจะตอบผิดเพราะความกำกวมของภาษา ไม่ใช่เพราะไม่รู้ศัพท์
ตัวเกมมีตัวกันชั้นหนึ่งอยู่ (`meaningsClash` ใน `src/deck.js`) แต่มันช่วยได้แค่กรณีที่ข้อความซ้อนกันตรง ๆ

## รู้ไว้ใช้ต่อ: แนวคิดที่ฝังอยู่ในโค้ดนี้

- **ความยากมาจาก "หน้าต่างเวลาตอบ" ไม่ใช่ "ความเร็วของวัตถุ"** — ระยะที่กำแพงเกิดถูกคำนวณย้อนกลับจากเวลา (`distanceOver()` ใน `main.js`) เกมจึงเร็วขึ้นได้เรื่อย ๆ โดยเวลาคิดไม่หดตามโดยบังเอิญ
- **แยกช่วงเวลาของภาระสมอง** — ภาระคิด (แปลคำ) กับภาระตอบสนอง (หลบ) ห้ามซ้อนกัน ไม่งั้นพังทั้งคู่
- **Input buffering** — ปุ่มที่กดระหว่างตัวละครกำลังเลื่อนต้องถูกเก็บไว้ทำต่อ ไม่ใช่ทิ้ง
- **ตัดสินคำตอบตอนแตะกำแพง ไม่ใช่ตอนกำแพงเข้าระยะ** — เพื่อให้การสไลด์วินาทีสุดท้ายยังทัน
- **Object pooling** — สร้างกำแพง/สิ่งกีดขวางไว้ล่วงหน้าแล้วใช้ซ้ำ ไม่สร้างใหม่ระหว่างเล่น
- **CanvasTexture ต้องวาดทับ ไม่ใช่สร้างใหม่** — ไม่งั้น VRAM รั่วจนเกมกระตุก
- **clamp `dt`** — สลับแท็บแล้วกลับมา `dt` จะพุ่งเป็นหลายวินาที วัตถุจะทะลุกำแพงไปโดยไม่ถูกตรวจการชน
- **อ่านปุ่มจาก `e.code` ไม่ใช่ `e.key`** — `e.key` เปลี่ยนตาม layout ถ้าสลับแป้นเป็นภาษาไทยแล้วกด WASD จะได้ "ไ ฟ ห ก" เกมจะไม่รับปุ่มเลย ส่วน `e.code` คือปุ่มทางกายภาพ ไม่เปลี่ยนตามภาษา (บั๊กนี้คนไทยเจอบ่อยมาก และเจ้าของเกมมักหาไม่เจอเพราะเทสต์ด้วยแป้นอังกฤษ)
- **ตัวละครประกอบจากรูปทรงพื้นฐาน — หัวใจอยู่ที่จุดหมุน** แขนขาต้องอยู่ใน `Group` ที่วางไว้ตรงข้อไหล่/สะโพก แล้วเลื่อน mesh ลงครึ่งความยาว ถ้าหมุนรอบจุดกึ่งกลางของตัว mesh เอง มันจะดูเหมือนกล่องลอยหมุน ไม่ใช่คนวิ่ง
- **ของที่ผ่านตัวไปแล้วต้องเก็บทิ้งเร็ว** — วัตถุที่อยู่ระหว่างตัวละครกับกล้องจะบานเต็มจอเป็นแผ่นสีทึบ ทั้งที่ในความเป็นจริงมันแค่กว้าง 2 เมตร
- **ให้แต่ละสื่อทำสิ่งที่มันเก่ง** — ข้อความให้ DOM (คมและใหญ่คงที่), พื้นที่และอันตรายให้ 3D (มีระยะ มีทิศทาง) การพยายามให้ 3D แบกตัวหนังสือคือที่มาของปัญหา "อ่านไม่ทัน" ทั้งหมดในเวอร์ชันแรก
- **ปลดล็อกเสียงจากการกดใด ๆ ในหน้า ไม่ใช่แค่ปุ่มควบคุมเกม** — ถ้าดักแค่ปุ่มลูกศร/Space คนที่เริ่มเกมด้วยการคลิกเมาส์จะไม่มีเสียงทั้งเซสชัน โดยไม่มี error ให้เห็น
- **ฟีเจอร์ที่พึ่งพาสิ่งที่ควบคุมไม่ได้ ต้องมีทางถอย** — โหมดฟังพึ่ง `speechSynthesis` ของเบราว์เซอร์ ถ้ามันไม่ทำงานแล้วเราไม่ทำอะไร ผู้เล่นจะเจอโจทย์ที่ไม่มีทางตอบถูก เกมจึงต้องตรวจจับแล้วสลับเป็นโจทย์ตัวหนังสือให้เอง
- **hitbox ที่ "ดูโดนแต่ไม่โดน" มักมาจากช่วงรับที่วางผิดจุด ไม่ใช่แคบเกิน** — บั๊กเก็บดาวไม่ติด "บางรอบ" เกิดเพราะยอดกระโดด (py 2.15) อยู่ *สูงเกิน* ตัวดาว (1.9) จนหลุดช่วงรับ ถ้าจังหวะกระโดดพอดีกับตอนดาวมาถึง = พลาด คำว่า "บางรอบ" คือเบาะแสว่าปัญหาอยู่ที่จังหวะ/ตำแหน่ง ไม่ใช่ตรรกะพัง
- **แคชคือศัตรูเงียบของ dev ที่ใช้ `http.server`** — มันไม่ส่ง cache header เบราว์เซอร์เลยแคชเอง แก้ไฟล์แล้ว reload เห็นของเก่า หาสาเหตุไม่เจอ ทางแก้คือเซิร์ฟเวอร์ที่ส่ง `Cache-Control: no-store` (ดู `serve.py`) — และ fetch ไฟล์ข้อมูล (deck) ด้วย `{cache:'no-store'}` อีกชั้น
