# ที่วางไฟล์โมเดลตัวละคร (.glb)

วางไฟล์ที่นี่ **ชื่อต้องตรงเป๊ะ** ตามนี้:

```
assets/models/astro.glb       🧑‍🚀 นักบินอวกาศ
assets/models/spartan.glb     🛡️ สปาตัน
assets/models/samurai.glb     ⚔️ ซามูไร
assets/models/ninja.glb       🥷 นินจา
assets/models/darklord.glb    🔴 ลอร์ดมืด
```

วางกี่ตัวก็ได้ ไม่ต้องครบ — ตัวไหนไม่มีไฟล์จะใช้ตัวที่ปั้นด้วยโค้ดต่อไป
เกมไม่พังแน่นอนไม่ว่าจะขาดตัวไหน **แนะนำให้เริ่มจากตัวเดียวก่อน** แล้วเทียบข้าง ๆ
กับตัวที่ปั้นเอง ก่อนจะตัดสินใจว่าจะเปลี่ยนทั้งชุดไหม

---

## ขั้นที่ 1: ตัวอ่านไฟล์ glTF — ✅ วางไว้ให้แล้ว

```
vendor/jsm/loaders/GLTFLoader.js
vendor/jsm/utils/BufferGeometryUtils.js
```

เป็นรุ่น 0.160.0 ตรงกับ `vendor/three.module.js` ที่เกมใช้อยู่ (คนละรุ่นกันจะพังแบบหา error ยากมาก)
ถ้าวันหลังอัปเกรด three ต้องโหลดสองไฟล์นี้ใหม่ให้ตรงรุ่นด้วย:

```bash
curl -o vendor/jsm/loaders/GLTFLoader.js \
  https://unpkg.com/three@0.160.0/examples/jsm/loaders/GLTFLoader.js
curl -o vendor/jsm/utils/BufferGeometryUtils.js \
  https://unpkg.com/three@0.160.0/examples/jsm/utils/BufferGeometryUtils.js
```

⚠️ **ห้ามหยิบมาแค่ GLTFLoader.js ไฟล์เดียว** — ข้างในมันอิมพอร์ตต่อไปยัง
`../utils/BufferGeometryUtils.js` ซึ่งเป็นเส้นทางสัมพัทธ์กับ *ตัวมันเอง*
ถ้าวางโดด ๆ มันจะไปหาไฟล์ผิดที่แล้วพังตอนโหลดตัวละครตัวแรก
โครงโฟลเดอร์ `jsm/loaders` + `jsm/utils` คือโครงเดิมของ three
วางตามนี้แล้วเส้นทางข้างในจะชี้ถูกเองโดยไม่ต้องแก้ไฟล์ที่โหลดมาเลย

## ⚠️ ขั้นที่ 3 (ลืมไม่ได้): เปิดสวิตช์ในตัวละครนั้น

**วางไฟล์ .glb อย่างเดียวยังไม่พอ** เกมจะไม่ไปแตะไฟล์เลยจนกว่าจะเปิดสวิตช์
เพิ่ม `model: {}` ในตัวละครที่ต้องการใน `src/characters.js`:

```js
ninja: {
  id: 'ninja', name: 'นินจา', ...
  model: {},        // ← บรรทัดนี้คือสวิตช์ ว่างไว้ก็ได้ ไม่ต้องใส่ค่าอะไร
},
```

**ทำไมต้องมีสวิตช์ ไม่ให้มันลองโหลดเองเลย?** เพราะการลองโหลดหมายถึงต้องดาวน์โหลด
ตัวอ่าน glTF ขนาด ~140 KB มาก่อนเสมอ **ผู้เล่นทุกคนจะต้องจ่ายค่าเน็ตก้อนนั้น
ตั้งแต่เปิดเกม ทั้งที่ส่วนใหญ่ไม่มีไฟล์โมเดลสักตัว** — ของที่เป็น "ทางเลือก"
ต้องไม่มีต้นทุนกับคนที่ไม่ได้เลือก

ช่องใน `model` ทั้งหมดเป็นตัวปรับจูนเผื่อโมเดลผิดแนว ปกติไม่ต้องใส่:
`faceZ: -1` (โมเดลหันหลังให้กล้อง) · `scale: 1.05` (อยากให้ใหญ่กว่าที่คำนวณให้)
· `yOffset` (เท้าลอย/จมติดมาในไฟล์)

## ข้อกำหนดของไฟล์

| หัวข้อ | ค่าที่ต้องการ | ถ้าไม่ตรงจะเกิดอะไร |
|---|---|---|
| นามสกุล | `.glb` (ไบนารีไฟล์เดียว) | `.gltf` แยกไฟล์ก็ได้ แต่ต้องวาง `.bin` + เทกซ์เจอร์ครบ |
| ขนาดตัว | ไม่สำคัญ | โค้ดวัดแล้วย่อ/ขยายให้สูง 1.65 หน่วยเอง |
| จุดหมุน | ไม่สำคัญ | โค้ดดันให้ฝ่าเท้าอยู่ที่พื้นเอง |
| หันหน้า | +Z (หันเข้าหาคนดู) | โค้ดหมุนกลับให้เอง · ถ้าตัวไหนหันหลังกลับ ตั้ง `faceZ: -1` ใน `characters.js` |
| อนิเมชัน | มีคลิปชื่อมีคำว่า `run` / `idle` / `jump` / `slide` | จับด้วยรูปแบบคำ ไม่ต้องตั้งชื่อเป๊ะ · ไม่มีคลิปวิ่งจะใช้คลิปแรกแทน |
| สามเหลี่ยม | ≤ 15,000 ต่อตัว | ตัวที่ปั้นด้วยโค้ดตอนนี้อยู่ที่ ~13,000 — ใช้เป็นเกณฑ์เทียบได้เลย |
| เทกซ์เจอร์ | ฝังในไฟล์ ≤ 1024px | ใหญ่กว่านี้ทำให้ไฟล์บวมโดยไม่เห็นความต่างที่ระยะ 150px |
| ขนาดไฟล์ | ≤ 800 KB ต่อตัว | รวมกัน 5 ตัวไม่ควรเกิน ~4 MB |
| **สัดส่วน** | **หัวโต ~2.6 หัว** | โมเดลสัดส่วนคนจริง (7 หัว) จะดูไม่เข้ากับร่างโกสต์ของเพื่อนร่วมห้อง ซึ่งใช้สัดส่วนตุ๊กตา |

## ⚠️ สิ่งที่จะ "หายไป" เมื่อเปลี่ยนไปใช้ .glb

โมเดลจากไฟล์เป็นก้อนเดียว เกมจึงไม่รู้ว่าชิ้นไหนคืออะไร → **ระบบอาวุธ 3 สถานะ
(มือเปล่า / พกไว้ / ชักออกมาถือ) จะใช้ไม่ได้กับตัวที่โหลดจากไฟล์**
ตัวที่ปั้นด้วยโค้ดยังทำได้เหมือนเดิมทุกอย่าง

ถ้าอยากได้กลับมา ต้องรู้ชื่อกระดูกมือในไฟล์นั้นก่อน แล้วค่อยแขวนอาวุธเข้ากับกระดูกนั้น
เปิดเกมแล้ววางบรรทัดนี้ใน console เพื่อดูรายชื่อกระดูกทั้งหมด:

```js
const { GLTFLoader } = await import('./vendor/jsm/loaders/GLTFLoader.js');
const g = await new GLTFLoader().loadAsync('./assets/models/ninja.glb');
const bones = []; g.scene.traverse(o => o.isBone && bones.push(o.name));
console.log(bones.join('\n'));
console.log('คลิป:', g.animations.map(a => a.name));
```

ส่งชื่อที่ได้มาให้ผม แล้วผมต่อระบบอาวุธเข้ากับกระดูกมือให้ได้
