# ที่วางไฟล์โมเดลตัวละคร (.glb)

## สถานะปัจจุบันของทั้ง 7 ตัว

| ตัวละคร | ใช้อะไร | ทำไม |
|---|---|---|
| 🥷 นินจา | `ninja.glb` ← KayKit **Rogue_Hooded** ย้อมดำ | ฮู้ดตรงเป๊ะ |
| 🛡️ สปาตัน | `spartan.glb` ← KayKit **Knight** ย้อมทองเหลือง | เกราะ + หมวกมีสัน + **โล่กลม** ครบ |
| 🌑 ลอร์ดมืด | `darklord.glb` ← KayKit **Skeleton_Warrior** ตาแดง + ดาบยืมจากไฟล์อื่น | หมวกมีเขา + ตาเรืองแสง (ตัวปั้นเองทำไม่ได้) |
| 🧙 พ่อมดน้อย | `mage.glb` ← KayKit **Mage** ย้อมแดงเลือดหมู + ไม้เท้า | หมวกแหลม + ผ้าคลุม อ่านเป็นพ่อมดทันที |
| 📖 แม่มดน้อย | `mage.glb` ← **ไฟล์เดียวกัน** ย้อมม่วง + **ถอดหมวก** + ตำราเปิด | ดูหมายเหตุคู่พ่อมดด้านล่าง |
| ⚔️ ซามูไร | **ตัวที่ปั้นด้วยโค้ด** | ดูหมายเหตุด้านล่าง |
| 🧑‍🚀 นักบินอวกาศ | **ตัวที่ปั้นด้วยโค้ด** | KayKit ไม่มีตัวละครอวกาศเลย |

⚠️ **คู่พ่อมดใช้ไฟล์ .glb ไฟล์เดียวกัน** ผ่านช่อง `model.file` (ไม่งั้นต้องเก็บ 525 KB ซ้ำสองก๊อบ
ทั้งที่ไบต์เหมือนกันเป๊ะ) — ซึ่งแปลว่ามันเสี่ยงกับบทเรียนข้อแรกของ `characters.js` เต็ม ๆ คือ
**ตัวละครที่ต่างกันแค่สี จะแยกไม่ออกที่ระยะ 150 px**

ทางออกคือใช้กฎที่บทเรียนนั้นบอกเองว่าชนะเสมอ — **เครื่องสวมหัว**

| | พ่อมด | แม่มด |
|---|---|---|
| หัว | หมวกแหลม | `hide: ['Mage_Hat']` → เห็นผม |
| มือ | ไม้เท้ายาว (`2H_Staff`) | ตำราเปิด (`Spellbook_open`) ระดับอก |
| เส้นรอบรูป | สูง แหลม | เตี้ย กลม มีของถือหน้าลำตัว |

> ถ้าวันไหนมีคนเอาหมวกกลับมาใส่ให้แม่มด สองตัวนี้จะกลายเป็นตัวเดียวกันทันที
> **หมวกไม่ใช่ของประดับในเกมนี้ มันคือตัวแยกตัวตน**

ℹ️ `Mage_Hat` กับ `Mage_Cape` ห้อยใต้ `head`/`chest` **ไม่ใช่**ใต้ `handslot.*`
จึงไม่ถูก `collectProps` เก็บไปซ่อนอัตโนมัติ — พ่อมดได้หมวกมาโดยไม่ต้องประกาศอะไร
ส่วนแม่มดต้องสั่ง `hide` เอง (คนละกลไกกับ `props` ที่ใช้กับของในมือ)

⚠️ **ซามูไรตั้งใจไม่ใช้โมเดลสำเร็จรูป** — ลอง KayKit Barbarian แล้วทั้งย้อมครามและย้อมแดง
ทั้งใส่ฮู้ดและถอดฮู้ด ผลคืออ่านเป็น "นักรบหมี" ทุกครั้ง เพราะ**เครื่องสวมหัวชนะเส้นรอบรูปเสมอ**
และ KayKit ไม่มีซามูไรหรืออะไรที่ใกล้เคียงเลย
> **โมเดลที่สวยกว่าแต่ผิดตัวตน แย่กว่าโมเดลที่หยาบกว่าแต่ถูกตัวตน**

## ตัวอย่างการปรับ: นินจา

`ninja.glb` = **KayKit "Rogue_Hooded"** (CC0, Kay Lousberg) ผ่านการปรับ 3 อย่าง:

| ปัญหาที่เจอจริง | วิธีแก้ | อยู่ที่ไหน |
|---|---|---|
| KayKit ไม่มีนินจา มีแต่โจรใส่ฮู้ด **สีเขียว** | ย้อมเฉพาะช่วงสีเขียวเป็นดำ ไม่แตะผิว/หนัง/เหล็ก | `model.recolor` |
| อาวุธติดมา 5 ชิ้น โผล่พร้อมกันหมด | ซ่อนทั้งหมด แล้วเปิดตามสถานะเกราะ | `model.props` |
| ผ้าคลุมหลังบังแขนขาในมุมที่เล่นจริง | ปิดถาวร | `model.hide` |
| ไฟล์ 3.4 MB (77 คลิป ใช้จริง 6) | ตัดคลิปที่ไม่ใช้ + บีบบัฟเฟอร์ → **533 KB** | `dev/prune-glb.py` |

```bash
python3 dev/prune-glb.py ต้นฉบับ.glb assets/models/ninja.glb Running_A Unarmed_Idle Jump_Idle Dodge_Forward Dodge_Left Dodge_Right
```

โหลดต้นฉบับได้จาก GitHub ของผู้ทำเอง (ไม่ต้องสมัครสมาชิก ไม่ต้องผ่านหน้า itch.io):
`github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0`
→ `addons/kaykit_character_pack_adventures/Characters/gltf/`
(ชุดโครงกระดูกอยู่ที่ `KayKit-Character-Pack-Skeletons-1.0`)

⚠️ **เวลาย้อมสี ต้องรู้ก่อนว่า "สีที่เห็นมาจากช่องไหน"** — มี 3 ทาง และแก้คนละที่:

| สีมาจาก | ตัวอย่าง | แก้ด้วย |
|---|---|---|
| เทกซ์เจอร์ (`map`) | ชุด/เกราะ/ผิวหนัง | `model.recolor` |
| `emissive` ล้วน ไม่มีเทกซ์เจอร์ | **ตาเรืองแสงของโครงกระดูก** (วัสดุชื่อ `Glow`) | `model.materials` |
| `color` ของวัสดุ | บางชุดใช้สีล้วนไม่มีเทกซ์เจอร์ | `model.materials` |

ผมเสียเวลาย้อมเทกซ์เจอร์ไปหนึ่งรอบเต็มเพราะเดาว่าตาเรืองแสงอยู่ในเทกซ์เจอร์ — มันไม่ได้อยู่

⚠️ **และอย่าเดาว่า "เกราะเหล็ก = สีเทา"** — Rogue ใช้เกราะ*อมฟ้า* (h195) แต่ Knight/Barbarian
ใช้เทาจริง ๆ ทั้งสองแบบต้องใช้กฎคนละอย่าง (`hue` กับ `grey: true`)
**วัดสีจริงจากไฟล์ก่อนเสมอ** ด้วยสคริปต์ท้ายหน้านี้

กับตัวที่ปั้นเอง ก่อนจะตัดสินใจว่าจะเปลี่ยนทั้งชุดไหม

## ⚠️ ขั้นที่ 3 (ลืมไม่ได้): เปิดสวิตช์ในตัวละครนั้น

**วางไฟล์ .glb อย่างเดียวยังไม่พอ** เกมจะไม่ไปแตะไฟล์เลยจนกว่าจะเปิดสวิตช์
เพิ่ม `model: {}` ในตัวละครที่ต้องการใน `src/characters.js`:

```js
ninja: {
  id: 'ninja', name: 'นินจา', ...
  model: {},        // ← บรรทัดนี้คือสวิตช์ ว่างไว้ก็ได้ ไม่ต้องใส่ค่าอะไร
},
```

**ทำไมต้องมีสวิตช์ ไม่ให้มันลองโหลดเองเลย?** เพราะการลองโหลดหมายถึงต้องดาวน์โหลด
ตัวอ่าน glTF ขนาด ~140 KB มาก่อนเสมอ **ผู้เล่นทุกคนจะต้องจ่ายค่าเน็ตก้อนนั้น
ตั้งแต่เปิดเกม ทั้งที่ส่วนใหญ่ไม่มีไฟล์โมเดลสักตัว** — ของที่เป็น "ทางเลือก"
ต้องไม่มีต้นทุนกับคนที่ไม่ได้เลือก

ช่องใน `model` ทั้งหมดเป็นตัวปรับจูนเผื่อโมเดลผิดแนว ปกติไม่ต้องใส่:
`faceZ: -1` (โมเดลหันหลังให้กล้อง) · `scale: 1.05` (อยากให้ใหญ่กว่าที่คำนวณให้)
· `yOffset` (เท้าลอย/จมติดมาในไฟล์)

## ข้อกำหนดของไฟล์

| หัวข้อ | ค่าที่ต้องการ | ถ้าไม่ตรงจะเกิดอะไร |
|---|---|---|
| นามสกุล | `.glb` (ไบนารีไฟล์เดียว) | `.gltf` แยกไฟล์ก็ได้ แต่ต้องวาง `.bin` + เทกซ์เจอร์ครบ |
| ขนาดตัว | ไม่สำคัญ | โค้ดวัดแล้วย่อ/ขยายให้สูง 1.65 หน่วยเอง |
| จุดหมุน | ไม่สำคัญ | โค้ดดันให้ฝ่าเท้าอยู่ที่พื้นเอง |
| หันหน้า | +Z (หันเข้าหาคนดู) | โค้ดหมุนกลับให้เอง · ถ้าตัวไหนหันหลังกลับ ตั้ง `faceZ: -1` ใน `characters.js` |
| อนิเมชัน | มีคลิปชื่อมีคำว่า `run` / `idle` / `jump` / `slide` | จับด้วยรูปแบบคำ ไม่ต้องตั้งชื่อเป๊ะ · ไม่มีคลิปวิ่งจะใช้คลิปแรกแทน |
| สามเหลี่ยม | ≤ 15,000 ต่อตัว | ตัวที่ปั้นด้วยโค้ดตอนนี้อยู่ที่ ~13,000 — ใช้เป็นเกณฑ์เทียบได้เลย |
| เทกซ์เจอร์ | ฝังในไฟล์ ≤ 1024px | ใหญ่กว่านี้ทำให้ไฟล์บวมโดยไม่เห็นความต่างที่ระยะ 150px |
| ขนาดไฟล์ | ≤ 800 KB ต่อตัว | รวมกัน 5 ตัวไม่ควรเกิน ~4 MB |
| **สัดส่วน** | **หัวโต ~2.6 หัว** | โมเดลสัดส่วนคนจริง (7 หัว) จะดูไม่เข้ากับร่างโกสต์ของเพื่อนร่วมห้อง ซึ่งใช้สัดส่วนตุ๊กตา |

## ⚙️ ระบบอาวุธ 3 สถานะ ยังใช้ได้กับ .glb

ตอนแรกคิดว่าจะหายไป แต่ชุดโมเดลที่ทำมาดีจะแถมอาวุธเป็น **mesh แยกชิ้น**
เสียบไว้ที่กระดูกจุดต่อมือ (ชื่อมักมีคำว่า `slot` / `socket` / `attach`)
เกมจึงแค่เปิด-ปิดชิ้นที่ต้องการตามสถานะเดิม ไม่ต้องเขียนระบบใหม่:

```js
model: { props: { stow: ['Knife_Offhand'], hold: ['Knife', 'Knife_Offhand'] } }
```

⚠️ ของพวกนี้มา **เปิดแสดงไว้ทั้งหมด** เพราะไฟล์ถูกทำมาให้ดูตอนพรีวิว
`models.js` จึงซ่อนทุกชิ้นที่เสียบอยู่ในจุดต่อ **ก่อน** วัดกล่องครอบ —
ถ้าวัดตอนหน้าไม้ยังกางอยู่ กล่องจะกว้าง 2.94 แทนที่จะเป็น 0.9 แล้วตัวละครถูกย่อผิดทั้งตัว

### ถ้าตัวละครมามือเปล่า — ยืมอาวุธจากไฟล์อื่นมาเสียบได้

โครงกระดูกของ KayKit ไม่มีอาวุธติดมาในไฟล์ **แต่กระดูกจุดต่อยังอยู่ครบ**
(`handslotl` / `handslotr`) เลยโหลดไฟล์อาวุธแยกมาแขวนเองได้:

```js
attach: [
  { name: 'Blade',    bone: 'handslotr', file: 'weapons/Skeleton_Blade.gltf' },
  { name: 'BladeOff', bone: 'handslotl', file: 'weapons/Skeleton_Blade.gltf' },
],
props: { stow: ['BladeOff'], hold: ['Blade', 'BladeOff'] },
```

**ไม่ต้องคำนวณตำแหน่ง/การหมุน/สเกลเองสักตัวเดียว** เพราะการเป็นลูกใน scene graph
แปลว่าได้ทรานส์ฟอร์มของพ่อมาทั้งชุดฟรี ๆ — กระดูกมือขยับตามอนิเมชันอยู่แล้ว
อาวุธที่แขวนใต้มันจึงขยับตามเองทุกเฟรม

⚠️ **ต้องแขวนหลัง normalize เสมอ** ไม่งั้นดาบที่ชูขึ้นจะถูกนับเป็นความสูงตัวละคร
แล้วตัวละครจะถูกย่อจนเตี้ยกว่าคนอื่น
(อาวุธที่ติดมาในไฟล์รอดมาได้เพราะมันวางแนวนอน — โชคช่วย ไม่ใช่การออกแบบ)

⚠️ ไฟล์ `.gltf` มักอ้าง `.bin` กับเทกซ์เจอร์แยก **ต้องวางไว้โฟลเดอร์เดียวกัน**

ดูชื่อ mesh/กระดูก/คลิปทั้งหมดในไฟล์ ด้วยการวางบรรทัดนี้ใน console:

```js
const { GLTFLoader } = await import('/vendor/jsm/loaders/GLTFLoader.js');
const g = await new GLTFLoader().loadAsync('/assets/models/ninja.glb');
```
